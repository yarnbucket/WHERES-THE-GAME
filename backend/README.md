# Where's the Game — Backend

This folder contains the backend API for **Where's the Game**, including:

- Express server (`app.js`)
- PostgreSQL database connection (`db/connect.js`)
- SQL query helpers (`db/queries.js`)
- Resolver logic (`logic/resolver.js`)
- API routes:
  - `/events`
  - `/channels`
  - `/streaming`
  - `/blackout`
  - `/resolve`
